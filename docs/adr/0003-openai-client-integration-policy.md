# ADR-0003: OpenAI API 공통 클라이언트 연동 정책

- 상태: Accepted
- 작성일: 2026-08-25
- 관련 Jira: RKT-25

## Context

리뷰 요약, 추천 문구, Local Tip 등 여러 기능에서 외부 GPT API를 사용할 예정이다. 각 기능이 직접 외부 API를 호출하면 인증 헤더, 요청 형식, 타임아웃, 재시도와 오류 처리가 중복되고 API Key가 여러 계층으로 퍼질 수 있다.

## Decision

- 외부 GPT API 호출은 `OpenAiClient` 하나로 추상화한다.
- HTTP 클라이언트는 현재 프로젝트에서 사용 중인 Spring `RestClient`를 사용한다.
- OpenAI Responses API의 `/v1/responses` 엔드포인트를 호출한다.
- API Key, Base URL, 모델명, 타임아웃, 재시도 설정은 환경변수와 Spring 설정으로 외부화한다.
- 기본 모델명은 `gpt-5.6-luna`로 두되, 실제 사용 가능한 모델 ID는 설정값으로 변경할 수 있게 한다.
- 429, 5xx, 네트워크 접근 오류만 제한적으로 재시도한다.
- API Key와 원문 프롬프트·응답은 로그에 기록하지 않는다.
- 이번 작업에서는 GPT API 호출 계층만 만들고, 리뷰 요약·Local Tip 같은 도메인 기능은 후속 티켓에서 연결한다.

## Consequences

- GPT 기능별 API 호출 코드가 중복되지 않고 공통 정책을 적용할 수 있다.
- 외부 API 장애와 응답 형식 변경의 영향 범위를 클라이언트 계층으로 제한할 수 있다.
- 실제 API 호출 테스트는 인증정보와 네트워크에 의존하므로 Mock HTTP 테스트를 기본으로 한다.
- 모델 변경 시 코드 수정 없이 설정 변경으로 대응할 수 있다.

## Follow-up

- 실제 OpenAI 계정에서 `gpt-5.6-luna` 사용 가능 여부를 확인한다.
- RKT-26에서 리뷰 요약 프롬프트와 응답 모델을 연결한다.
- 운영 환경에서 사용량·비용·응답 실패율 모니터링을 추가한다.
